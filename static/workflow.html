AAutopilot: two sheets, no one needed

Give the student sheet (one row per copy) and the accounts sheet (columns admin, evaluator, password: one admin + evaluator pair per row). Check sheets reads both tabs once and shows each test with the inputs worked out from the sheet (exam type, class, subject from the test name's brackets, total marks); correct any before starting. Each pair then takes whole tests in sheet order: it fetches the question paper and Model Answer from the portal, checks the marks, checks and uploads every copy, then takes the next test. A test it cannot do is skipped with the reason, except that a test the portal has no Model Answer for waits for you to give one below, and a test whose marks do not add up waits for the marks. Before the first start, Sign in the windows opens every ID's portal window: the ones already signed in stay hidden, and each one that is not comes on screen for you to sign in once (it hides itself after; the login is kept on this computer). The windows then work hidden; one comes on screen only when it needs you (Portal windows, below). Checking never waits for the portal: every checked copy is saved in Checked copies\<batch> - <test> next to this app (named after the student) and uploaded behind, so a portal that says "Unable to fetch task" only delays the uploads. A pair takes its next test as soon as every copy of its test is checked. Steps 1-3 below are not needed for the autopilot.

5Alerts

When a run stops (finished, paused for a sign-in, or a portal window waiting for a login), this computer shows a Windows notification (no sound) and a banner on this page, and emails the run's alert address from the sender below.

6Portal logins

When a portal Chrome window is logged out, it signs itself in again with its own ID and this password (the same password for every ID). The password is stored encrypted on this computer and is never shown again. If the portal refuses the password, that ID is not tried again until you save the password again, so a wrong password cannot lock the account: its window comes on screen for you to sign in, and you get a notification and email. A sign-in that only missed (a slow portal) is tried again by itself.
